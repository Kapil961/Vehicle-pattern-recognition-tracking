# Vehicle Pattern Recognition and Tracking from Video

## Project Overview

This project aims to develop a deep learning and computer vision
system that recognizes vehicle characteristics and analyzes vehicle
movement patterns from video footage.

## Objectives

- Detect vehicles in video frames.
- Recognize vehicle categories and, where supported by the dataset,
  vehicle colors, makes, and models.
- Track vehicles across consecutive frames.
- Analyze vehicle trajectories and movement directions.
- Extract vehicle counts and traffic-flow patterns.
- Investigate movement and congestion patterns where the available
  video data supports reliable analysis.
- Evaluate the implemented models using appropriate metrics.

## Planned Technologies

- Python
- PyTorch
- OpenCV
- Ultralytics YOLO
- Deep learning classification models
- NumPy and Pandas
- Matplotlib

The final technology choices and project scope will be confirmed
after inspecting the available datasets and testing compatibility
with the development environment.

## Project Status

Phase 0: Initial project setup.

## Dataset

The dataset has not yet been finalized. Dataset suitability,
annotation coverage, licensing, and storage requirements will be
investigated before model training.

## Evaluation

Evaluation metrics will be selected according to the tasks and
available ground-truth annotations. Experimental results will be
added only after the experiments have been performed.
